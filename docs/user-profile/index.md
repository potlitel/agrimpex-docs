# Perfil de Usuario

## Descripción

La página de Perfil de Usuario permite visualizar y administrar los datos personales y preferencias del usuario autenticado dentro del sistema Agrimpex.

## Acceso

1. Menú: **Perfil de Usuario** (o ruta directa)
2. Ruta directa: `/profile`

## Componentes

- **Información del perfil:** datos del usuario (nombre, correo) y su estado de acceso
- **Preferencias:** ajustes de visualización y comunicaciones asociados al usuario
- **Roles asociados:** según el perfil, pueden verse los roles o grupos del usuario

:::note
La administración completa de usuarios se realiza desde [Gestión de Usuarios](/docs/administracion/usuarios).
:::
