# Verificación de Documentos

## Descripción

El sistema Agrimpex permite verificar documentos de importación mediante códigos de verificación. La verificación puede realizarse de forma pública (sin iniciar sesión) a través de `/verify` y dentro del sistema autenticado.

## Acceso

1. Página pública: `/verify`
2. Sistema interno: desde el menú principal del backoffice

## Flujo de Verificación

1. Ingresa el código de verificación proporcionado
2. El sistema valida el código
3. Se muestra el estado del documento verificado

## Página Pública

La página pública permite verificar un documento sin acceso al sistema interno. Es útil para validar documentos entregados por proveedores o interlocutores.

## Verificación Interna

La verificación interna se realiza dentro del flujo del sistema autenticado; consulte [Verificación de Documentos](/docs/verification) para detalles.
