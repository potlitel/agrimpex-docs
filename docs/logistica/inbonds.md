# Entradas de Contenedores (Inbonds)

## Descripción

El módulo de entradas de contenedores registra la recepción de contenedores en terminales y recintos. Permite llevar un control del momento de llegada, número de contenedores, terminal de destino y detalles del evento de entrada.

## Acceso

1. Menú: **Logística** → **Entradas de Contenedores (Inbonds)**
2. Ruta directa: `/logistic/inbonds`

## Funcionalidades

- **Registro de entrada:** agregar una nueva entrada con los datos del contenedor y terminal
- **Listado:** ver todas las entradas realizadas con su estado
- **Filtros:** filtrar entradas por terminal, fecha o estado

:::info
Las entradas registradas en este módulo alimentan el flujo de contenedores de la terminal de destino.
:::
