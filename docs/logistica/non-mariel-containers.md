# Contenedores No Mariel

## Descripción

El módulo de contenedores no Mariel gestiona los contenedores que no asumen el flujo estándar de Mariel. Permite identificar y controlar el ciclo de vida de contenedores que ingresan al sistema por vías alternativas, manteniendo trazabilidad con el sistema de contenedorización.

## Acceso

1. Menú: **Logística** → **Contenedores No Mariel**
2. Ruta directa: `/logistic/non-mariel-containers`

## Funcionalidades

- **Listado de contenedores no Mariel:** ver contenedores con su estado de carga y ubicación
- **Visualización de detalles:** clic en un contenedor para ver su historial de movimientos

:::note
Esta página complementa la gestión de contenedores de las terminales Mariel/SCU documentada en [Contenedores](/docs/logistica/contenedores).
:::
