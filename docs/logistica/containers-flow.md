# Contenedores - Flujo

## Descripción

El módulo de flujo de contenedores permite rastrear y visualizar el movimiento de los contenedores entre terminales, recintos y puntos de operación. Proporciona una vista dinámica del estado y ubicación actual de cada contenedor.

## Acceso

1. Menú: **Logística** → **Contenedores - Flujo**
2. Ruta directa: `/logistic/containers-flow`

## Componentes

- **Mapa/Tabla de flujo:** visualización del estado actual y ubicación de los contenedores
- **Historial:** rastreo de movimientos anteriores del contenedor

:::info
El flujo se actualiza en tiempo real según los movimientos registrados en el sistema.
:::
