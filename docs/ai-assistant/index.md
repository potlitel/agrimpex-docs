# Asistente IA

## Descripción

El módulo de Asistente IA permite acceder a un chat asistente para obtener ayuda sobre el uso del sistema Agrimpex. El asistente puede responder preguntas sobre procesos, proporcionar guías y asistir en la búsqueda de información dentro del manual de usuario.

## Acceso

1. Menú: **Asistente IA**
2. Ruta directa: `/ai-assistant`

## Componentes

### Chat

Interfaz de conversación con el asistente:

- **Entrada de mensajes:** escribe tu pregunta y presiona Enter
- **Historial:** conversación anterior de la sesión
- **Respuestas:** el asistente responde con ayuda basada en el manual de usuario

:::info
El asistente no sustituye el manual: para consultas específicas de procesos, revisa las páginas de la documentación correspondiente.
:::
