# Módulo de Reportes

## Descripción

El módulo de Reportes permite generar y visualizar reportes estadísticos del sistema. Proporciona:

- **Reportes de Exportación:** exportación de datos del sistema a archivos
- **Reportes de Monitoreo:** indicadores de estado y rendimiento del sistema
- **Listado de Reportes:** lista de reportes generados con acceso a los resultados

## Acceso

1. Menú: **Reportes**
2. Ruta directa: `/reports`

## Componentes

- **Export Reports:** generar reportes de exportación con filtros de datos
- **Monitoring Reports:** reportes de monitoreo del estado de procesos
- **Reports List:** listado y vista previa de los reportes generados

:::info
Los reportes generados pueden descargarse desde el listado una vez completado su generación.
:::
