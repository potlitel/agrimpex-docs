# Configuración

## Descripción

El módulo de Configuración permite ajustar y administrar las configuraciones del sistema, como el nivel de acceso, preferencias de visualización y parámetros de operación. Proporciona una forma controlada de gestionar las opciones de ambos, sobre la base de los permisos y roles del usuario.

## Acceso

1. Menú: **Configuración** (acciones relacionadas con configuración)
2. Ruta directa: `/settings`

## Componentes

- **Ajustes de seguridad:** administración de permisos y niveles de acceso
- **Preferencias de visualización:** configuración del idioma y estilo de la interfaz
- **Parámetros operativos:** ajustes de comportamiento general del sistema

:::note
Las configuraciones aplican por perfil de usuario; los cambios típicamente requieren el rol correspondiente.
:::
