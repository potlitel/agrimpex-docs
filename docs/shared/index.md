# Componentes Compartidos y Librerías

## Descripción

El sistema Agrimpex cuenta con componentes compartidos y librerías internas que apoyan las funcionalidades del backoffice:

- **Crud Table:** componente de tablas genéricas para listados con búsqueda y paginación
- **Interceptor:** gestión de interceptores HTTP para las peticiones del sistema
- **Pipes:** transformadores de datos para formato de fechas, texto y valores
- **Directivas:** directivas de Angular para comportamientos del DOM y validación
- **Document Verification:** servicios y modelos de verificación de documentos
- **Servicios compartidos:** servicios transversales del sistema
- **Librerías (libs/):** handlers de formularios y listados y librerías UI de apoyo

## Propósito

Estos componentes permiten un desarrollo eficiente y mantenible de las funcionalidades del sistema, reutilizando la lógica común en múltiples módulos.

:::info
Estos son componentes internos de la arquitectura del sistema; su uso es transparente para el usuario final.
:::
