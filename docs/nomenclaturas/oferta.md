# Ofertas

## Descripción

El catálogo de Ofertas permite gestionar las ofertas comerciales asociadas a las cargas del sistema, para llevar el control de las condiciones de negociación comercial.

## Acceso

1. Menú: **Nomenclaturas** → **Ofertas**
2. Ruta directa: `/management/nomenclatures/oferta`

## Funcionalidades

- **Listado:** ver todas las ofertas registradas
- **Visualización de detalles:** consultar la información de cada oferta
- **Estado:** seguimiento del estado de la oferta
