# Direcciones de Descarga

## Descripción

El catálogo de Direcciones de Descarga permite gestionar las direcciones de remate de descarga asociadas a las operaciones logísticas del sistema.

## Acceso

1. Menú: **Nomenclaturas** → **Direcciones de Descarga**
2. Ruta directa: `/management/nomenclatures/download-address`

## Funcionalidades

- **Listado:** ver todas las direcciones de descarga registradas
- **Registro:** agregar nuevas direcciones
- **Visualización de detalles:** consultar la información de cada dirección
