# Consejos de Pueblo

## Descripción

El catálogo de Consejos de Pueblo permite gestionar los grupos de población o comunidades locales asociados a los procesos logísticos y administrativos del sistema.

## Acceso

1. Menú: **Nomenclaturas** → **Consejos de Pueblo**
2. Ruta directa: `/management/nomenclatures/peoples-council`

## Funcionalidades

- **Listado:** ver todos los consejos registrados
- **Registro:** agregar nuevos consejos
- **Visualización de detalles:** consultar la información de cada consejo
