# Estados de Solicitud de Permiso

## Descripción

El catálogo de Estados de Solicitud de Permiso permite gestionar los estados asociados a las solicitudes de permisos en el sistema, para llevar el seguimiento del estado de las solicitudes realizadas.

## Acceso

1. Menú: **Nomenclaturas** → **Estados de Solicitud de Permiso**
2. Ruta directa: `/management/nomenclatures/status-application-permit`

## Funcionalidades

- **Listado:** ver los estados registrados
- **Registro:** agregar nuevos estados de solicitud de permiso
- **Visualización de detalles:** consultar la información de cada estado
