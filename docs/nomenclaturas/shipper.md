# Embarcadores (Shipper)

## Descripción

El catálogo de Embarcadores permite gestionar los remitentes (shippers) de la mercancía asociados a las operaciones del sistema, para mantener el control del origen de carga.

## Acceso

1. Menú: **Nomenclaturas** → **Embarcadores (Shipper)**
2. Ruta directa: `/management/nomenclatures/shipper`

## Funcionalidades

- **Listado:** ver todos los embarcadores registrados
- **Registro:** agregar nuevos embarcadores
- **Visualización de detalles:** consultar la información de cada embarcador
