# Provincias

## Descripción

El catálogo de Provincias permite gestionar las provincias asociadas a las cargas del sistema, para mantener el control de la ubicación de destino de la mercancía.

## Acceso

1. Menú: **Nomenclaturas** → **Provincias**
2. Ruta directa: `/management/nomenclatures/province`

## Funcionalidades

- **Listado:** ver todas las provincias registradas
- **Registro:** agregar nuevas provincias
- **Visualización de detalles:** consultar la información de cada provincia
