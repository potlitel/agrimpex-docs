## Propósito

Índice de los nomencladores activos disponibles para la gestión del sistema.

## Acceso

- **Menú:** Nomenclaturas → Nomencladores
- **Ruta directa:** `/management/nomenclatures`
- **Componente:** `NomenclaturesComponent`
