# Marcas

## Descripción

El catálogo de Marcas permite gestionar las marcas comerciales asociadas a los productos del sistema, para mantener el control y seguimiento de la propiedad intelectual de las mismas.

## Acceso

1. Menú: **Nomenclaturas** → **Marcas**
2. Ruta directa: `/management/nomenclatures/brand`

## Funcionalidades

- **Listado:** ver todas las marcas registradas
- **Registro:** agregar nuevas marcas
- **Visualización de detalles:** consultar la información de cada marca
