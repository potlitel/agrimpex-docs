# Puertos

## Descripción

El catálogo de Puertos permite gestionar los puertos marítimos asociados a las operaciones de importación y exportación en puerto de contenedores del sistema.

## Acceso

1. Menú: **Nomenclaturas** → **Puertos**
2. Ruta directa: `/management/nomenclatures/port`

## Funcionalidades

- **Listado:** ver todos los puertos registrados
- **Registro:** agregar nuevos puertos
- **Visualización de detalles:** consultar la información de cada puerto
