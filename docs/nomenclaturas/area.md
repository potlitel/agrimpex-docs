# Áreas

## Descripción

El catálogo de Áreas permite gestionar las áreas geográficas o departamentos utilizados en el sistema para clasificar ubicaciones, plantas y otros elementos geográficos.

## Acceso

1. Menú: **Nomenclaturas** → **Áreas**
2. Ruta directa: `/management/nomenclatures/area`

## Interfaz

### Listado de Áreas

![Listado de Áreas](/img/nomenclaturas/area-listado.png)

## Campos

| Campo | Tipo | Descripción |
|-------|------|-------------|
| Código | Texto | Código identificador del área |
| Nombre | Texto | Nombre del área |
| Descripción | Texto | Descripción adicional |
| Activo | Booleano | Si el área está activa |

## Crear Área

1. Accede al módulo de Áreas
2. Haz clic en **"+ Agregar Área"**
3. Ingresa el código (ej: AREA-001)
4. Ingresa el nombre
5. Agrega descripción (opcional)
6. Selecciona el estado activo
7. Guarda el registro

## Editar Área

1. Busca el área en la tabla
2. Haz clic en el botón de edición
3. Modifica los campos necesarios
4. Guarda los cambios

## Eliminar Área

:::danger ADVERTENCIA
No puedes eliminar un área que esté asociada a plantas, ubicaciones u otros registros.
:::
