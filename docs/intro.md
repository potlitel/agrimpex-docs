# Introducción

## ¿Qué es Agrimpex?

**Agrimpex** es un sistema integral de gestión de importaciones desarrollado por **EICMA Soft** (Cuba). La plataforma permite administrar de manera eficiente todo el ciclo de vida de las importaciones comerciales, desde la solicitud hasta la entrega final.

## Propósito del Sistema

Agrimpex está diseñado para:

- **Gestionar el proceso completo de importaciones**: Desde la solicitud inicial hasta la entrega al cliente.
- **Controlar contenedores y logística**: Seguimiento de contenedores, estados de carga, desaduanaje y entregas.
- **Administrar catálogos y nomenclaturas**: Países, tipos de contenedor, operadores, plantas, permisos, etc.
- **Mantener trazabilidad**: Registro de todas las operaciones para auditoría y seguridad.
- **Gestionar usuarios y permisos**: Control de acceso basado en roles.

## Tecnología

- **Frontend**: Angular + TailwindCSS
- **Backend**: Symfony (API Platform) con JWT
- **Base de datos**: MySQL
- **Documentación**: Docusaurus
